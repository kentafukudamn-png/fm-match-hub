# FM Match Hub

Football Manager のセーブデータ運用を支援する **試合記録・分析・試合準備** プラットフォームです。
ビルド不要・依存ライブラリなしの静的 Web アプリで、`index.html` をブラウザで開くだけで動作します。

## 機能

| 画面 | 内容 |
| --- | --- |
| ダッシュボード | シーズン成績サマリー、次の試合（準備の進捗）、直近フォーム、得点ランキング、最近の試合 |
| 試合記録 | 日付・大会・対戦相手・スコア・フォーメーション（自/相手）・戦術・スタッツ（ポゼッション、シュート、xG 等）・得点者/アシスト/時間・選手評価・MOM・振り返りメモ |
| 分析 | シーズン/大会で絞り込み。累計勝ち点と得失点差の推移グラフ、平均スタッツ、フォーメーション別・相手フォーメーション別・H/A別・大会別・戦術別・対戦相手別の成績、選手成績、自動インサイト（xG との乖離、ホーム/アウェイ差、終盤の得点傾向など） |
| 試合準備 | 対戦相手スカウティング（想定フォーメーション、スタイル、キープレイヤー、強み/弱み）、ゲームプラン（戦術、指示、セットプレー、試合中のプラン）、スタメン候補、準備チェックリスト。入力中に **過去の対戦成績** と **推奨フォーメーション**（相手フォーメーション別・対戦相手別・全体の実績から算出）を表示。「試合結果を記録」で準備内容を引き継いで試合記録へ |
| スカッド | 選手登録（一括追加可）、ポジション・状態（負傷/出場停止など）管理、個人成績 |
| 設定 | クラブ名・シーズン、**FM から取り込み**、JSON エクスポート/インポート、試合記録の CSV 出力、サンプルデータ |

## 使い方

```bash
# そのまま開く
open index.html

# またはローカルサーバーで起動
npm start   # http://localhost:5173
```

おすすめの流れ: 設定でクラブ名とシーズンを入力 → スカッド登録 → 試合準備を作成 → 試合後に「試合結果を記録」→ 分析で傾向を確認 → 次の準備へ反映。

## FM から取り込む（最新のセーブデータの数字）

FM のセーブデータ本体（`.fm`）は独自の圧縮形式のため直接は読めませんが、FM の **印刷（書き出し）機能** を使えば数クリックで取り込めます。

1. FM で **スカッド** 画面（選手成績）または **クラブ → 日程** 画面（試合結果）を開く
   - 表示列は「ビュー」で調整（例: 背番号・名前・ポジション・出場・得点・アシスト・平均評価・出場時間・PoM）
2. **Ctrl+P**（Mac は **⌘+P**）→「**Web ページ**」（または「テキストファイル」）で保存
3. アプリの **設定 → FM から取り込む**（スカッド画面右上のボタンからも可）でファイルを選択（複数可）→ プレビューを確認して取り込み

- スカッド／日程は列名（英語版・日本語化の両方に対応）から自動判別します。
- 選手は名前で照合し、背番号・ポジションと **FM 成績**（出場・得点・アシスト・平均評価・PoM など）を更新。スカッド画面に「FM 〜」列として表示されます。
- 試合は日付＋対戦相手で照合し、スコアを更新（入力済みのスタッツ・メモ・評価は保持）。未消化の試合はスキップ。何度取り込んでも重複しません。

## データの保存先

- **ブラウザ内（localStorage）**: 常に保存されます。
- **クラウド保存（GitHub の非公開リポジトリ）**: 設定画面から接続すると、変更が自動で `fm-data.json` としてコミットされ、PC・スマホなど複数端末で同期できます。保存ごとにコミットされるため、GitHub の履歴がそのままバックアップになります。サーバーは不要で、ブラウザから GitHub API に直接アクセスします。

### クラウド保存の設定手順

1. GitHub で **Private** リポジトリを作成（データ専用のブランチを作る場合はそのブランチ名も控える）
2. 設定画面の「こちらからトークンを作成」を開く（名前・期限90日・Contents: Read and write が入力済み）
3. Repository access で **Only select repositories** → データ保存用の非公開リポジトリ **だけ** を選び、「Generate token」
4. 設定画面に保存先（オーナー・リポジトリ・ブランチ）とトークンを入力して「接続」
5. 他の端末でも同じ手順で接続すると、クラウドのデータが読み込まれます

## セキュリティ

- **データは非公開リポジトリにのみ保存**: 公開リポジトリは接続時に拒否します。アプリ本体（このコード）にはデータ・トークン・個人の設定は含まれません。
- **トークン**: 権限を「1つの非公開リポジトリの Contents 読み書き」だけに絞った Fine-grained token を使用してください（クラシックトークンは警告）。トークンは GitHub API（`api.github.com`）以外には送信されず、データファイルにも含まれません。
  - 「このブラウザにトークンを記憶する」をオフにすると、ブラウザを閉じた時点で消え、次回は再入力になります。共用 PC ではオフにしてください。
  - 期限切れ・漏えいの疑いがあるときは、設定画面から差し替え、GitHub の[トークン一覧](https://github.com/settings/personal-access-tokens)で古いトークンを削除してください。
  - 「接続を解除」でブラウザからトークンを削除します。
- **通信先の制限 (CSP)**: 読み込めるのは自サイトのファイルのみ、通信先は GitHub API のみに制限しています。外部ライブラリ・広告・解析タグは一切使っていません。
- **不正なデータ対策**: インポート・同期したデータは読み込み時に無害化し、画面表示時はすべてエスケープします。
- **埋め込み防止**: 他サイトの iframe 内では動作しません。検索エンジンにも登録されないよう設定しています。

```
css/style.css   スタイル（ライト/ダーク対応）

js/app.js       画面描画・ルーティング・イベント
tests/          ユニットテスト（集計・同期）
```

```bash
npm test
```
